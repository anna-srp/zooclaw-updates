# 修复：API 定价页写清模型与工具的实际计费单位，并标明哪些能力当前免费、沙箱怎么算钱

## 核心宣传点

API Pricing 页之前有一部分模型和工具只写了含糊的「按用量结算」，也没区分当前免费的能力和要收费的数据源请求，看完还是不知道一次调用大概花多少。现在中英文的 /pricing?product=api 和 /zh/pricing?product=api 都明确写出模型和第三方工具与原服务商同价、平台不额外加价，并在价格表里直接给出已确认的计费单位和条件。语音、知识库和 ZooData 本身标为目前免费；小红书和其他已列明的社交数据请求分别给出单价和分页规则；图像、视频、搜索、正文提取也补上了价格和计费条件，「更多 Agent 能力」里的穿搭工具说明了按变体计价。沙箱价格卡片突出三件事：按运行时长计费、空闲会自动休眠、休眠期间不产生沙箱费用，而模型和工具调用另外单独计费。改动只涉及页面文案与价格表展示，后端扣费逻辑没有任何变化。
