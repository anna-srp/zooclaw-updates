# 工作台 R3 改进：首页卡片不再乱跳、日程支持自然语言与时区、设置页独立侧栏

## 核心宣传点

这一版把首页、Agent 编辑面板、日程和设置导航一起理顺了。首页 Agent 卡片不会再因为聊天统计异步返回或重新排序就自己横移，第一张卡片始终可见，手动滑动和左右翻页都保留。日程页的月份、星期、今天、空状态和运行状态全部跟随语言，Cron 改成自然语言展示并标明时区，原表达式仍能在编辑器里看到；计划时间按任务自己的时区算再转到日历时区，跨天和夏令时都覆盖到了。每个任务每天只显示一行，计划时间和真实运行结果分开，只有真正跑成功的一次性任务才打完成标记，不会再"时间过了就算成功"。新建/编辑日程表单加了必填校验，名称自动聚焦、拒绝纯空格，保存取消固定在顶部。设置页换成独立二级侧栏，图标和返回入口补齐，侧栏与正文独立滚动，窄屏外观选项不再溢出。

## PR 说明

## 修改内容

统一首页、Agent 编辑面板、日程和设置导航的工作台交互。本 PR 已完整收录 #3784（`7d6089c92`）和 #3785（`250d617b8`）的变更，并保留原提交历史；三组改动集中在此审查。

- **首页卡片**：修复异步聊天统计返回、Agent 重新排序后列表自动横移的问题，首张卡片保持可见；保留手动滑动、左右翻页和边缘渐隐。
- **Agent 编辑面板**：Settings / Profile 面板和顶部标签栏沿用聊天区域背景，跟随浅色、深色主题；浅色输入框、下拉框、撤销及 Add 按钮使用白色底，与面板略作区分。
- **日程展示（#3784）**：月份、星期、今天、空状态和运行状态跟随语言；Cron 用自然语言展示并标明时区，原表达式保留在编辑器和提示中。按任务时区计算计划，再转换到日历时区，覆盖跨天与夏令时。
- **日程状态与表单（#3784）**：每个任务每天显示一行，计划时间与真实运行结果分开；仅真实成功的一次性任务显示完成标记，不再把时间经过当作执行成功。新建/编辑表单使用必填校验，名称自动聚焦并拒绝纯空格，保存和取消固定在顶部。
- **设置导航（#3785）**：设置页使用独立二级侧栏，与 Agent 详情页共用导航按钮和主题 hover；补齐图标、统一返回入口，标题移入内容区，侧栏与正文独立滚动；保留手机菜单展开收起并修复窄屏外观选项溢出。
- **本地预览（#3785）**：补齐默认 mock 场景的用量记录响应，修复 Usage 预览异常。

## 原因与实现

首页 CSS Scroll Snap 会在 DOM 重排时跟随原先吸附的卡片，导致非用户触发的横移；移除这两排列表的吸附。编辑面板原本覆盖全局背景变量，改为继承工作台背景，并将控件底色独立配置。

日程使用 lockfile 固定版本的 `cron-parser` 和 `cronstrue` 处理时区及自然语言计划。缺少时区、间隔锚点或完整历史时，使用已知后端时间和真实运行记录，不推算成功次数。设置导航统一使用设计系统按钮及共享侧栏组件。
