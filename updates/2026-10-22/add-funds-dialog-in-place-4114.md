# 充值弹窗改为原地打开，不再被强行跳到 Billing 页

## 核心宣传点

过去点击侧边栏的 Add funds 会先跳转到 Billing 页再弹出充值窗口，当前页面的筛选、滚动位置全部丢失。现在充值弹窗由页面框架统一承载，在 API keys、Webhooks、用量等任意页面都能原地打开，背景页面、地址、筛选状态与滚动位置都保留，关闭后焦点回到原入口；外部深链接仍然可用，关闭时只移除对应参数。首充优惠卡与充值提醒只在一级导航展示，设置页二级导航不再重复；引导卡与弹窗统一使用平台品牌色和同一套礼物素材，卡片高度从 190px 压到 138px。后台账单读取失败时会保留已打开的弹窗和已填金额并暂停提交，恢复后继续，权限失效才丢弃会话。
