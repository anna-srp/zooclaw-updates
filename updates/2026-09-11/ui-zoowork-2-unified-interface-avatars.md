# ZooWork 2.0 界面统一：输入框、导航、空状态插画和默认头像全套升级

## 核心宣传点

ZooWork 2.0 这次把各个页面的视觉和交互拉到了同一套标准上，解决的是那种"用着别扭但说不清哪里别扭"的问题——首页和 Agent 详情页的输入框长得不一样、空状态位置偏移、创建 Agent 弹窗布局松散。

**聊天输入框终于统一了**。首页、Agent 对话和构建页现在共用同一套描边、轻阴影、模型选择、附件和发送入口。顺带修了一个边界情况：已选的模型如果不在可选目录里，名称仍然能正常显示，但不会被重新塞回可选列表。

**全局样式收敛**。浅灰导航配近白内容背景，Agent 详情页左右区域之间那条分割线去掉了；个人资料入口间距压缩，设置页二级导航与内容背景保持一致。

**导航和创建流程**。创建弹窗和共享链接二级弹窗改用设计系统重做，左上角加了返回入口；最近会话只保留单行名称；旧项目入口的下划线改成常显，列表底部分割线间距从 40px 收紧到 16px。Connector、MCP、Skills、Knowledge Base 现在从侧栏直接进入，重复的 Plugins 标题和顶层选项卡都移除了。

**空状态和插画**。正式的空状态、连接异常及 404 插画接入并居中展示。素材库真正为空时隐藏筛选栏，但有筛选条件时保留恢复入口——这个区分挺重要，避免用户以为素材丢了。

**默认头像**。10 款 Agent 默认头像 + 11 款用户动物头像（已上传 R2）。新 Agent 创建时会持久化默认头像；用户头像按 UID 稳定分配，同一账号跨页面、跨设备保持一致，并且优先保留已有头像。
