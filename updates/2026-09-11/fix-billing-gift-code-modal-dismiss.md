# 修复：礼品码兑换弹窗一点输入框就消失，输完还得先按回车才能兑换

## 核心宣传点

账户菜单里的「Redeem Gift Code」弹窗之前基本处于不可用状态：**点一下输入框，弹窗就没了**。勉强输进兑换码之后，还必须先按回车，直接点 Redeem 按钮也没反应。现在这两个问题都修好了，输入和点击都正常。

**根因是事件时序**。兑换弹窗通过 Portal 渲染到 `document.body`，DOM 上位于账户菜单范围之外。菜单的外部点击监听在 mousedown 阶段就把弹窗内的操作误判成"点到外面了"，于是在按钮的 click 事件触发之前就把菜单和弹窗一起关掉了。原有测试只触发 click，正好绕过了这个事件顺序，所以没测出来。

**改动三处**：弹窗打开时由弹窗自己负责关闭，避免账户菜单提前把它卸载掉；Escape 改成分层关闭，先关兑换弹窗，再按一次才关账户菜单；兑换请求处理中忽略重复提交，防止连续按回车打出多个请求。
